**ClueTrail** is a web-based platform that lets users explore, analyze, and discuss mysterious cold cases.  
Built using **Python (Flask)** for the backend and **HTML, CSS, JavaScript, SQL, and JSON** for the frontend, it integrates with the **Unsplash API** to provide immersive visuals and background imagery for each case.

---

## 🚀 Features

- 📂 Browse and analyze unsolved cold cases  
- 🧠 JSON-based structured data for clues and case details  
- 🖼️ Auto-fetch real-world visuals using the Unsplash API  
- 🔍 Search and filter by case name, location, or tags  
- 🧩 Responsive and dark-themed UI built for engagement  
- 💬 Easy-to-extend Flask backend with modular design
